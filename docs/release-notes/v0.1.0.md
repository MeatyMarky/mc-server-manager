Minecraft Server Manager runs Minecraft servers on your own computer: it downloads the
server files, starts and stops them, shows you the console, installs mods and plugins, and
keeps backups. It handles as many servers as you like side by side, each with its own
version, memory and mods. Nothing is uploaded anywhere — every world, backup and setting
stays on your machine.

This is the first release. It is a 0.1.0 in the honest sense: everything below works and is
tested, and it has not been used by anybody except its author.

## What it does

**Servers.** Vanilla, Paper, Purpur, Fabric, Forge and NeoForge. Versions come from each
project's own list rather than a hardcoded table, so both numbering schemes are there — the
classic `1.21.4` line and the calendar line Mojang moved to (`26.1`, `26.2`). The version
picker is a table with release dates, because two hundred entries in a dropdown is a scroll
bar and a guess.

**Java, handled for you.** The app finds every Java on the computer, works out which one a
given server needs from Mojang's own metadata, and picks accordingly. When nothing suitable
is installed it offers to download a Temurin JDK — naming the version and the size first —
and shares that one copy between every server that needs it. It refuses to pick a 32-bit
JVM, tells you when a mod loader wants a different Java version than the one you have, and
never silently swaps one for another.

**Mods and modpacks.** Browse Modrinth and CurseForge from inside the app, with categories,
sorting and content types filtered to what your server can actually load. Dependencies are
resolved and shown for confirmation before anything downloads. You pick the file, or take
the newest that fits; installed mods can be switched to any other version, downgrades
included. `.mrpack` modpacks import too, and installing a pack creates the server it needs.

**A web map.** Tick the box when creating a server and it installs
[squaremap](https://modrinth.com/mod/squaremap): flat, vanilla-looking tiles you pan around
in a browser, on a port nothing else on the machine is using. It gets its own tab, opens on
your world's spawn rather than on 0,0, and offers to render what you have already played.

**Backups.** Manual or scheduled, with retention by count and by age. A running server is
quiesced properly first — saving off, world flushed, wait for confirmation — so an archive
is never torn, and saving is turned back on even if the backup fails. Restores take a safety
copy of what they are about to replace.

**And the rest.** Live console with search and command history, `server.properties` editing
that keeps your comments and formatting, ops and whitelist management that works whether the
server is running or not, world switching and import, CPU and memory charts, LAN/VPN/public
address discovery with an honest port check, and optional UPnP port forwarding that only
ever happens on a click.

## Two things to know before you install

**The installers are not signed.** Windows SmartScreen will show a blue box saying the
publisher is unrecognised. Choose **More info**, then **Run anyway**. This is not a judgement
about the file — it means nobody has paid for a code-signing certificate, which costs a few
hundred a year and requires a registered company or a verified identity. The alternative was
not shipping. If that is not good enough for you, the source is here and
`pnpm tauri build` produces the same installers.

**The Linux builds are untested.** They compile in CI, and the code is written to be
portable — every path is a `PathBuf`, every executable name is chosen per platform, no shell
commands are assembled by hand. But nobody has actually run the app on Linux. The `.deb` and
the AppImage in this release might work perfectly or might not start at all, and there is no
way to know without you. If you try it, please say what happened either way — there is a
[Linux report](../../issues/new?template=linux_report.yml) issue template, and "it worked" is
as useful a report as a crash.

## Known limitations

- **CurseForge needs your own API key.** CurseForge requires every application to use its
  own key and forbids shipping one inside a distributed app, so the browser lists CurseForge
  as available-but-unconfigured until you paste a key into Settings. It is free to get.
  Modrinth needs nothing.
- **The web map is visible on your local network.** squaremap's web server binds `0.0.0.0`,
  which is its own default and not something this app changes. Anyone who can reach your
  computer on that port can see your map. The Networking tab lists exactly which addresses
  those are.
- **Forge and NeoForge installs are slow the first time.** Their installers run for a minute
  or two and download a hundred libraries. That is them, not this.
- **No macOS build.** The code has no Windows-only assumptions beyond the ones Tauri handles,
  but nothing has been built or tested there.

## Requirements

Windows 10 or 11, or a Linux desktop with WebKitGTK 4.1. Java is not a requirement — the app
will offer to fetch one.

## When something goes wrong

The **?** button in the top right writes a problem report: the app log, its view of your
Java installs, the server console and a startup self-check. It shows you the full contents
before it writes the file, and nothing is uploaded. Attaching one to an issue turns most
reports from a guessing game into an answer.

`docs/troubleshooting.md` covers the errors that come up most: no Java, wrong Java, port
already in use, the server exiting immediately, and what SmartScreen is doing.
